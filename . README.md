# Binance Trading Bot

Real-money ready bot with EMA + RSI strategy.

## Setup
1. `git clone <your-repo>`
2. `python -m venv venv && source venv/bin/activate` (or venv\Scripts\activate on Windows)
3. `pip install -r requirements.txt`
4. `cp.env.example.env` and fill your Binance API keys
5. `python bot.py`

## Safety
- API key must have ONLY Spot Trading enabled. NO withdrawals.
- Test on testnet first: https://testnet.binance.vision/
- Start with small QUANTITY.

## How to change strategy
Edit `strategy.py` - you don't need to touch `bot.py`.
